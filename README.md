# Farid Rojas — Portafolio

Sitio personal para Vercel: Inicio, Servicios, Currículum, Proyectos y Contacto.

## Stack
HTML + CSS + JS (estático). Ideal para desplegar en Vercel sin build.

## Local
Abre `index.html` en el navegador o sirve la carpeta:

```bash
npx serve .
```

## Deploy en Vercel
1. Entra a https://vercel.com/new
2. Importa el repo `FaridRojas23/FaridRojasdev`
3. Framework: **Other** (o déjalo en Auto)
4. Deploy

## Personalizar
- Nombre / textos: archivos `.html`
- Correo del formulario: `site.js` (mailto)
- Colores: `styles.css` (`--accent`)
- Foto: reemplaza el avatar `FR` en `index.html` por una `<img>`
